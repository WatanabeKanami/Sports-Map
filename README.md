# いまスポ — 江東区スポーツマップ

「運動したい」を「今からできる」に変える、都知事杯オープンデータ・ハッカソン向けのWebアプリです。

時間・予算・人数・気分・屋内外の希望から、江東区でできる運動を最大3件提案します。現在地または選択したエリアを起点に距離を計算し、給水スポット、クーリングシェルター、公衆トイレ、AEDも同じ地図で確認できます。

## パイロット地域とは

本格展開の前に、小さな範囲で使い勝手やデータ品質を確かめる最初の地域です。初期版は、関連するオープンデータが比較的揃っている江東区を対象にしています。

## 技術構成

- React + TypeScript: 画面の状態管理と型安全な推薦ロジック
- vinext + Vite: Reactアプリの開発サーバーと高速なビルド
- Leaflet + OpenStreetMap: 施設と支援スポットの地図表示
- 静的JSON: 小規模なMVPで運用しやすいデータ管理
- Cloudflare / Sites: 配信とホスティング

静的JSONは扱いやすく費用もほぼかかりませんが、料金や営業情報の即時更新には向きません。そのため、確認日と公式ページへのリンクを必ず表示しています。

## ローカル起動

Node.js `22.13.0` 以上を使います。

```bash
npm install
npm run dev
```

`http://localhost:3000` を開いて確認できます。

## チェック

```bash
npm run lint
npm test
```

`npm test` は本番ビルド、サーバーレンダリング、公開データの最低限の整合性を確認します。

## データと注意事項

使用データ、ライセンス、加工内容、既知の制約は [public/data/ATTRIBUTION.md](public/data/ATTRIBUTION.md) にまとめています。

- 初期版の料金は一部施設のみ公式情報を手動確認
- 予約空き、臨時休館、設備の稼働状況はリアルタイムではない
- 距離は直線距離の目安
- 現在地は端末内の距離計算にだけ使い、保存・送信しない
- 本サービスは東京都・江東区の公式サービスではない
